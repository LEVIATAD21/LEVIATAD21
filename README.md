## 👋 Sobre mim

Sou **Kawã Silva dos Santos**, desenvolvedor de software em evolução contínua, com foco em **Backend e desenvolvimento Full-Stack**. Uso projetos próprios para praticar a construção de aplicações web, APIs, automações e soluções orientadas a requisitos reais.

Tenho interesse especial em **Linux, automação e fundamentos de Segurança da Informação**. Priorizo código legível, documentação objetiva, validação de entradas, controle de acesso e entregas que possam ser demonstradas e verificadas.

**Objetivo profissional:** oportunidade como **Desenvolvedor de Software Júnior** ou **Backend Developer Júnior**, contribuindo com projetos reais enquanto continuo aprofundando minha base técnica.

## 🧭 Foco técnico

- **Backend e APIs:** lógica de aplicação, integração entre serviços, autenticação e validação.
- **Desenvolvimento web:** construção de interfaces e integração entre frontend e backend.
- **Dados:** SQL, modelagem e fundamentos de bancos de dados relacionais.
- **Linux e automação:** terminal, Bash e scripts para simplificar tarefas.
- **Segurança:** fundamentos de sistemas operacionais, controle de acesso, proteção de credenciais e validação de entradas.
