# Métricas de tecnologias do portfólio

Snapshot: 14/11/2026. Fonte: árvores Git da branch padrão main, consultadas pela integração GitHub autorizada.

## Universo e limites

Foram acessíveis 18 repositórios de LEVIATAD21. O repositório do perfil foi excluído; os 17 restantes possuíam arquivos de código reconhecidos. Todas as árvores retornaram truncated=false. Os totais incluem repositórios privados; os dados publicados são agregados, sem inventário de nomes privados.

Cada repositório conta uma vez por linguagem. Variantes e projetos relacionados não são deduplicados e podem compartilhar código. Arquivos de testes e configurações são contados; o snapshot não atribui autoria individual. Não é GitHub Linguist, contagem de linhas ou nota de competência.

## Filtro e grupos

Excluídas pastas node_modules, vendor, dist, build, coverage, .next, .expo, venv, .venv, __pycache__, assets e public/assets. Somente blobs com extensões reconhecidas entram no painel.

- TypeScript: ts, tsx
- JavaScript: js, jsx, mjs, cjs
- Python: py
- SQL: sql
- HTML: html
- CSS: css, scss
- Shell: sh, bash

Docker: existência de Dockerfile. GitHub Actions: existência de YAML em .github/workflows. Não se afirma que os testes passaram ou que houve deploy. Frameworks foram identificados em manifests de dependências lidos, não derivados de uma porcentagem de linguagem.

## Preservação das habilidades

As tecnologias do README anterior foram mantidas. A ausência de uma tecnologia neste snapshot não invalida conhecimentos adquiridos; indica apenas ausência de arquivos reconhecidos no universo consultado.

## Atualização

As métricas são estáticas e têm data explícita. Para atualizar, repita a coleta das árvores, aplique os filtros acima e atualize conjuntamente skills-evidence.json, skills-evidence.svg e a tabela do README. Não publicar código, nomes ou detalhes de projetos confidenciais para aumentar o painel.
